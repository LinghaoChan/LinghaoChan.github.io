# Images Folder

This folder should contain the following images:

## Required Images:
- `lhchen.png` - Your profile photo (circular crop recommended)
- `name.png` - Chinese name image (120px width)
- `thu.png` - Tsinghua University logo
- `xdu.png` - Xidian University logo
- `motionlcm.png` - MotionLCM project image
- `humanmac.png` - HumanMAC project image
- `unimocap.png` - UniMoCap project image

## Optional Images:
- `humantomato.gif` - HumanTOMATO animated demo
- `new.gif` - "NEW" badge animation
- `hot.gif` - "HOT" badge animation

## Image Guidelines:
- Profile photo: 300x300px, circular crop
- University logos: 70x70px
- Project images: 160px width
- Use high-quality images with good contrast
- Optimize for web (PNG/JPG format)

## Temporary Placeholders:
Until you add the actual images, the site will use:
- External URLs for some images (HumanTOMATO gif)
- Missing image placeholders for local files

## How to Add Images:
1. Save your images in this folder with the exact names listed above
2. Refresh the webpage to see the changes
3. Make sure image paths in HTML match the filenames exactly
